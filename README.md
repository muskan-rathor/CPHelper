# 🧮 CPHelper (Competitive Programming Utility Library - Java)

A reusable Java library that contains pre-written, optimized, and modular implementations of algorithms and data structures used in **competitive programming** and **DSA practice**.

This library helps reduce repetitive coding during contests and improves speed, readability, and consistency.

---

## 🚀 Features

### 🔢 Math Utilities
- GCD, LCM, Modular Power (`powMod`)
- Modular Multiplication & Inverse
- Prime Checking, Sieve of Eratosthenes (planned)

### 📊 Array Utilities
- Reverse, Prefix Sum, Min/Max
- Custom Binary Search (Lower/Upper Bound)

### 🧭 Graph Algorithms
- BFS, Dijkstra’s shortest path
- Disjoint Set Union (Union–Find)

### ⚙️ Miscellaneous
- Utility templates for random number generation, safe comparison, etc. *(to be added)*
